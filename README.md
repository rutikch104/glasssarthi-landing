# GlassSarthi Landing

Standalone marketing site for Nestify / static hosting.

## Local

```bash
npm install
npm start
```

Opens at `http://localhost:3000`.

## Build (Nestify / production)

```bash
npm install
npm run build
```

Serve the `build/` folder. Typical settings:

- **Build command:** `npm run build`
- **Publish directory:** `build`
- **Node:** 18+ recommended

## App links

Log in / Get started / Start free point to the product app via `REACT_APP_APP_URL`
(see `.env.example`). Default is `http://13.49.84.127`.

## Notes

This repo is landing-only. The main GlassShop app stays in `GlassShop_updated_Code`.
